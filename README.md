# ☕ Meus Projetos e Exercícios em Java

Este repositório foi criado para organizar e centralizar todos os códigos, algoritmos e projetos práticos desenvolvidos por mim durante o curso Técnico em Informática no IFRS. O objetivo é consolidar meu aprendizado em lógica de programação e no paradigma de Orientação a Objetos (POO).

---

### 📚 O que estou estudando e praticando aqui:
* **Conceitos Básicos:** Sintaxe do Java, estruturas condicionais (`if/else`), estruturas de repetição (`while/for`) entre outros.
* **Orientação a Objetos:** Criação de classes, atributos, métodos.
* **Resolução de Problemas:** Exercícios de lógica voltados para o desenvolvimento do raciocínio algorítmico.

### 🛠️ Tecnologias e Ferramentas Utilizadas:
* **Linguagem:** Java
* **Ambiente de Desenvolvimento (IDE):** VS Code / Geany
* **Gerenciamento de Versão:** Github
