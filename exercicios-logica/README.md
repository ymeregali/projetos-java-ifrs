# 🏋️‍♂️ Exercícios de Lógica e Algoritmos

Esta pasta contém os meus códigos e resoluções de problemas práticos desenvolvidos em Java. O foco principal aqui é o desenvolvimento do raciocínio lógico e o domínio das estruturas fundamentais da programação.

### 🧠 O que estou praticando aqui:
* **Estruturas Condicionais:** Tomadas de decisão no código utilizando `if`, `else if` e `else`.
* **Estruturas de Repetição:** Loops e laços de repetição utilizando `while` e `for` para automação de tarefas.
* **Operadores:** Utilização de operadores aritméticos (soma, subtração, etc.), relacionais (maior, menor, igual) e lógicos (`AND`, `OR`).
* **Entrada e Saída de Dados:** Leitura de dados do teclado com a classe `Scanner` e exibição de resultados no console.

### 📝 Exemplos de problemas resolvidos:
- Cálculo de médias de notas escolares.
- Verificação de maioridade ou categorias de idade.
- Contadores, tabuadas e repetições de mensagens.
- Simuladores simples (como cálculo de aumento de salário ou bônus).

_A cada nova aula e lista de exercícios do professor, novos códigos são adicionados aqui!_ 🚀
